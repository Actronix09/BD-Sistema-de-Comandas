# Diccionario de Datos del Sistema de Comandas

En este documento se describe cada columna de las tablas resultantes de la transformación del modelo EER, con su tipo, sus restricciones y su significado. Corresponde a la Parte 6.4 de la Práctica 3.

---

**Base de datos:** `comandas` (PostgreSQL 16.4)

**Origen:** generado desde el catálogo del gestor después de ejecutar [`sql/esquema.sql`](<../sql/esquema.sql>). Las descripciones son los `COMMENT ON` del propio esquema, así que el diccionario y la base no pueden contradecirse.

**Contenido:** 17 tablas y 97 columnas.

---

## Convenciones

| Marca | Significado |
| :-- | :-- |
| `PK` | Forma parte de la clave primaria (implica `NOT NULL`) |
| `FK → tabla` | Clave foránea, con sus acciones referenciales |
| `UNIQUE` | Clave alternativa |
| `IDENTITY` | El gestor asigna el valor (`GENERATED BY DEFAULT AS IDENTITY`) |
| `GENERATED ALWAYS … STORED` | Columna generada: la calcula el gestor a partir de otra columna y no se puede escribir |
| `NULL` | Admite nulos |

Los `CHECK` que involucran varias columnas aparecen en cada una de ellas.
